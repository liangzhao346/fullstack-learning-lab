## 关键决定

- 默认配置标为 H2 文件数据库 + local-demo 进程内缓存；MySQL/Redis 只标为可选配置、未实测。
- 页面四个入口是同一 `App.vue` 中的标签切换，不虚构前端 Router 或额外服务。
- 商品列表、订单查询与库存写入直接走 SQL；商品详情走业务缓存。
- 区分 requestKey（订单幂等）、requestId（单次 HTTP 追踪）和 version（商品编辑冲突）。
- 缓存指标不是全部 SQL 的总数；实验的 HTTP 200 不表示所有实验子请求成功。
